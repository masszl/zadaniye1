# Описание ER-диаграммы

1. roles → users (1:N)
Одна роль может принадлежать нескольким пользователям.

2. users → orders (1:N)
Один пользователь может оформить несколько заказов.

3. products → stock_items (1:N)
Один товар может иметь несколько размеров.

4. sizes → stock_items (1:N)
Один размер может относиться к разным товарам.

5. orders → order_items (1:N)
Один заказ может содержать несколько позиций.

6. stock_items → order_items (1:N)
Одна товарная позиция может встречаться в разных заказах.
